# 山熏 · 贵客送黑客松（Guikesong）评审指南

> Topic: `Guikesong` · 传统腊肉工艺 × 数字化溯源 × 车间 IoT

## 30 秒看懂

| 问题 | 方案 |
|------|------|
| 消费者不信任腊肉来源 | 扫码溯源 H5，全环节故事 + 师傅签名 |
| 厂内批次难管理 | 批次全生命周期 + 3D 车间 + 温湿度监测 |
| 数据分散 | 统一数据层 `SX_API` + 演示 JSON |

## 在线演示

| 入口 | URL | 密码 |
|------|-----|------|
| 厂内管理 | `/admin.html` 或 `/山熏_demo.html` | `1234` |
| 消费者溯源 | `/trace.html?t=SXQZ260703` | `demo` |

## 3 分钟演示脚本（建议）

1. **消费者视角（60s）**  
   打开溯源 H5 → 登录 `demo` → 向下滑动浏览「腊肉的一生」→ 展示师傅剪影与环节大图

2. **厂内视角（90s）**  
   打开厂内端 → 登录 `1234` → 「今日」看工艺模块 → 「批次」筛选在库批次 → 打开溯源二维码

3. **技术亮点（30s）**  
   说明双端架构、数据脱敏开源、可部署 Demo

## 架构一览

```
消费者扫码 → trace.html（溯源故事）
                    ↑
厂内管理端 → 山熏_demo.html → SX_API → data/demo/*.json
                    ↓
              TraceAPI → localStorage + trace-records.json
```

## 代码导航（评审快速定位）

```
js/
├── core/           # 配置 + 数据 API 层
├── domain/         # 业务模块（批次、溯源、常量）
├── app/boot.js     # 启动入口
api/trace.js        # 溯源客户端
trace.html          # 消费者 H5
山熏_demo.html      # 厂内管理（UI + 3D 车间）
data/demo/
├── batches.json    # 批次主数据
├── trace-records.json  # 溯源演示记录
└── readings.json   # 温湿度读数（64 条真实结构）
```

## 创新点

1. **工艺故事化溯源**：不是冷冰冰的字段列表，而是全屏沉浸式环节叙事  
2. **厂内 + 消费者双端**：同一批次数据，内外视角权限分离  
3. **IoT 规则引擎演示**：温湿度 64 条实测 + 自动异常聚合（晾挂批次 QZ-2608-01）
